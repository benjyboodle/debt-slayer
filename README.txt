DEBT SLAYER PHONE APP

This is a free Progressive Web App prototype.

FILES
index.html = the actual app
manifest.json = tells supported phones to treat it as an app

EASIEST FREE SETUP
1. Create a free GitHub account at github.com if you do not already have one.
2. Create a new repository named debt-slayer.
3. Upload index.html and manifest.json.
4. In the repository, open Settings, then Pages.
5. Set the source to Deploy from a branch.
6. Select the main branch and the root folder, then save.
7. GitHub will give you a website address.
8. Open that address in Safari on your iPhone.
9. Tap Share.
10. Tap Add to Home Screen.
11. Name it Debt Slayer and tap Add.

IMPORTANT
The game data is stored locally on the device. Your debt information is not uploaded to GitHub.
The public repository contains the app code, not your personal game state.
Auto attacks are game records only. They never move money from a bank account.
The app catches up scheduled auto attacks when you open it.

The demo starts with example balances of $6,000 and $24,000. Edit or delete these before using it for your actual debts.
